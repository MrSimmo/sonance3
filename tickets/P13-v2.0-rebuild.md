# P13 — Sonance v2.0 Clean Rebuild (from P11a baseline)

## Context
Rolled back to P11a baseline (all UI work P1–P10 intact, media key registration working). The P11c gapless implementation broke AVPlay activation and cascaded into visualiser issues. This rebuild re-implements lost features on a clean foundation, then properly activates AVPlay.

## Phase Order

| Phase | Description | Dependencies |
|-------|-------------|-------------|
| P13a | Star/unstar favourites | None — API + UI only |
| P13b | Artist detail page | None — new screen |

## Baseline State (P11a)
- All screens: Home, Library, Search, Album Detail, Playlists, Now Playing, Queue, Settings
- Split-pane album detail with scrollable tracklist
- Paginated library (50 items per page)
- FocusManager with d-pad navigation
- Colour button queue management (Yellow/Blue/Red)
- Exit dialogue on Back from main screens
- Login with IME navigation fix
- Media key registration (P11a)
- All Chromium 63 compatibility fixes (no flex gap, grid-gap, no backdrop-filter, etc.)
- HTML5 Audio playback (single element, working on both browser and TV)
- .wgt packaging and Jellyfin2Samsung deployment

## Chromium 63 Rules (apply to ALL phases)
- NO flex `gap` — use margin on children
- Use `grid-gap` not `gap` on grids
- NO `backdrop-filter` — use `filter: blur()` on elements
- NO `aspect-ratio` CSS — use padding-bottom trick
- NO optional chaining `?.`, nullish coalescing `??`, Array.flat(), Object.fromEntries(), top-level await
- NO `scrollIntoView` with options object — use manual scroll
- `webkitAudioContext` as fallback for `AudioContext`

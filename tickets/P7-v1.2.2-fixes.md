# P7 — Sonance v1.2.2 Final Polish Fixes

## Overview
Six remaining issues from P6 testing in browser. All are CSS/styling fixes.

## Tasks

### P7.1 — Now Playing: Black Bar Still Visible at Bottom
**Problem:** The black bar at the bottom of the Now Playing screen persists.
**Fix:**
- The issue is that the Now Playing screen's background/container does not extend to the very bottom of `#content-area`
- Debug approach: temporarily add `background: red` to `#content-area` when NP is active to see if the gap is between the NP screen container and the content area, or between the content area and the viewport
- Likely fix: the NP screen container needs `min-height: 100%` AND the content area itself needs `height: 100%` (not just flex: 1)
- Ensure the `.np-active` class on `#content-area` sets: `padding: 0 !important; margin: 0 !important; overflow: hidden !important;`
- The NP screen root div must be: `position: absolute; top: 0; left: 0; right: 0; bottom: 0; overflow: hidden;`
- Also check: is `#content-area` using `min-height` vs `height`? It needs `height: 100%` or `flex: 1` with the parent being `display: flex; flex-direction: column; height: 100%`
- Nuclear option if the above doesn't work: make the NP background a direct child of `#main` (not `#content-area`) positioned absolutely to fill the entire main area

### P7.2 — Now Playing: Play/Pause Button Shape and Highlight
**Problem:** The play/pause button changes from rounded-rectangle to circle when focused. It should stay as a rounded rectangle (the boxy shape) at all times. When focused, it should turn pink — not change shape.
**Fix:**
- The play/pause button should ALWAYS be a rounded rectangle (e.g. `border-radius: 16px`, NOT `border-radius: 50%`)
- The button should ALWAYS be white background with dark icon in its default (unfocused) state
- When focused: `background: var(--accent)` (#e44d8a), icon stays white. The subtle glow can remain: `box-shadow: 0 0 24px rgba(228, 77, 138, 0.4)`
- The size must NOT change between focused and unfocused states — same width, same height, same border-radius
- Check if there are two different elements being swapped (a circle version and a square version) or if the border-radius is being changed by the focus class. Fix whichever is happening.
- Ensure: `width: 52px; height: 52px; border-radius: 16px;` in both focused and unfocused states

### P7.3 — Library Tabs: Active Tab Reshaping on Focus
**Problem:** When the user highlights the already-active tab (e.g. "Albums"), it changes from a compact rounded-rectangle pill to a larger, more rounded shape. The tab should keep its exact shape — only the text colour should change.
**Fix:**
- The active tab pill has a specific `border-radius` (e.g. 20px) and `padding`. These must NOT change when the tab also receives focus.
- Check if the `.focused` class is adding `border-radius`, `padding`, `transform: scale()`, or any size-changing property to tab elements
- The focused+active state should be: same shape, same size, same background — just change the text to `--accent` colour and weight 600
- Explicitly override for library tabs:
  ```css
  .library-tab.focused {
      transform: none !important;
      padding: 9px 26px !important;  /* same as unfocused */
      border-radius: 20px !important;  /* same as unfocused */
  }
  ```
- The active tab background (`rgba(255,255,255,0.1)`) should remain unchanged when focused

### P7.4 — Home Page: Shuffle Button Focus Should Be Text-Only
**Problem:** When the Shuffle button on the Home hero is highlighted, the entire button fills with pink. It should only change the text/icon colour to pink, not fill the background.
**Fix:**
- Shuffle button unfocused: `background: rgba(255,255,255,0.08); border: 1px solid var(--border); color: var(--text-primary)`
- Shuffle button focused: same background, same border, but `color: var(--accent)` and the icon SVG stroke/fill changes to `--accent`. NO background change.
- Only the Play button should fill with pink when focused (it's already pink, so it gets brighter: `filter: brightness(1.15)`)
- Remove any `.focused` rule that sets `background: var(--accent)` on the Shuffle button specifically
- The distinction: Play = action button (fill highlight), Shuffle = secondary button (text highlight)

### P7.5 — Album Detail: Inconsistent Item Sizes
**Problem:** Items in the album grid on the Library page are rendering at different sizes — some album cards are larger than others.
**Fix:**
- This is likely caused by images loading at different aspect ratios or the grid items not having a fixed aspect ratio
- Set a fixed height on the album art container: `aspect-ratio: 1 / 1` (if supported on Chromium 63) or use the padding-bottom trick: `height: 0; padding-bottom: 100%; position: relative;` with the image absolutely positioned inside
- **Check Chromium 63 support:** `aspect-ratio` was NOT supported until Chrome 88. Use the padding trick instead:
  ```css
  .album-art-wrapper {
      width: 100%;
      height: 0;
      padding-bottom: 100%;
      position: relative;
      overflow: hidden;
      border-radius: 8px;
  }
  .album-art-wrapper img,
  .album-art-wrapper .placeholder {
      position: absolute;
      top: 0; left: 0;
      width: 100%; height: 100%;
      object-fit: cover;
  }
  ```
- Ensure ALL album cards in the grid use the same wrapper, whether they have real art or the placeholder
- The text below (title, artist) should be outside the aspect-ratio wrapper

### P7.6 — Exit Dialogue: Text Highlight, Not Box Fill
**Problem:** The Cancel button fills with pink when focused. Should only highlight the text pink, not the whole button. The Exit button is red — should be consistent pink.
**Fix:**
- Cancel button unfocused: `background: var(--bg-elevated); color: var(--text-primary)`
- Cancel button focused: `background: var(--bg-elevated); color: var(--accent); font-weight: 600` — same background, pink text only
- Exit button unfocused: `background: var(--bg-elevated); color: var(--text-primary)` — same as Cancel, NOT red
- Exit button focused: `background: var(--bg-elevated); color: var(--accent); font-weight: 600` — same as Cancel
- Both buttons look identical when unfocused. When focused, only the text turns pink. No background change, no fill, no border.
- Remove the red colour from the Exit button entirely. Both buttons should be visually identical except for their labels.

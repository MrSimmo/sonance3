# P6 — Sonance v1.2.1 Bugfixes & Polish

## Overview
Targeted bugfixes and highlight consistency improvements from TV testing of v1.2.

## Prerequisites
- Read CLAUDE.md, PROGRESS.md
- All patches P1–P5 applied

## Tasks

### P6.1 — Now Playing: Increase Background Blur
**Problem:** Blur on the album art background isn't strong enough.
**Fix:** In the Now Playing screen CSS, increase `filter: blur(50px)` to `filter: blur(100px)` on the `.np-bg-image` element. Keep `saturate(1.3)`.

### P6.2 — Now Playing: Black Bar When Player Bar Slides Away
**Problem:** When the Now Playing bar slides down off-screen, it leaves a black strip at the bottom.
**Fix:** 
- The Now Playing screen container must extend all the way to the bottom of the viewport — `bottom: 0` with no gap
- When the bar is hidden (`.np-bar-hidden`), the content area's bottom padding should become 0
- The Now Playing screen's background must fill to the absolute bottom edge
- Check if there's a gap between the content area bottom and the viewport bottom — the NP screen should use `position: absolute; top: 0; left: 0; right: 0; bottom: 0` within `#content-area`, and `#content-area` itself should have `padding-bottom: 0` when NP screen is active
- Also ensure the NP bar's `translateY(100%)` pushes it fully off-screen — if the bar has a top border, that border may still be visible. Hide the bar with `visibility: hidden` after the transition ends, or use `transform: translateY(calc(100% + 2px))` to account for borders

### P6.3 — Now Playing: Play/Pause Focus Style
**Problem:** The play/pause button changes shape/size when focused instead of just changing colour. Other transport icons show a faint blurred border highlight.
**Fix:**
- Play/pause button: when focused, do NOT change the size, shape, or add any border/outline. Instead add a subtle pink glow: `box-shadow: 0 0 24px rgba(228, 77, 138, 0.5)`. Keep the button exactly the same size.
- Remove ANY `outline`, `border`, or `box-shadow: 0 0 0 Xpx` highlight on transport control icons (shuffle, prev, next, repeat). When focused, these icons should ONLY change their fill/stroke colour to `--accent` (#e44d8a). No borders, no outlines, no glows on the small icons.
- Ensure `.focusable.focused` styles are overridden specifically for `.np-control-btn` elements with `outline: none !important; box-shadow: none !important; transform: none !important;`
- The play/pause circle is the exception — it gets the glow but no size change

### P6.4 — Search Screen: Add Padding Between Keyboard and Results
**Problem:** The keyboard and Quick Access/results panels are crammed together with no gap.
**Fix:** Add `gap: 32px` (or `margin-left: 32px` on the results panel) between the keyboard panel and the results panel in the search screen's flex layout. Currently they're likely `gap: 0` or very small.

### P6.5 — Tracklist: Fix Highlight Width and Text Shift
**Problem:** In the album detail tracklist, the pink border highlight is too wide (extends beyond the track row) and the track number shifts left / duration shifts right when focused.
**Fix:**
- The focus highlight on track rows should NOT change the element's width or cause any horizontal layout shift
- Use `box-shadow: inset 0 0 0 1.5px var(--accent)` instead of `outline` or `border` for track row focus — this doesn't affect layout
- Alternatively, if using outline, set `outline-offset: -2px` so it stays within the element bounds
- Remove any `padding` or `margin` changes on `.focused` track rows
- Ensure the track row is `overflow: hidden` so highlights don't bleed outside
- The track number and duration must stay in exactly the same position regardless of focus state — verify no `transform: scale()` is applied to track rows

### P6.6 — Artists Page: Fix Truncated Highlight
**Problem:** Pink highlight border on artist cards is clipped/truncated by the grid container.
**Fix:**
- Add `padding: 8px` to the artists grid container to give the outlines room
- Or switch artist card focus from `outline` to `box-shadow: 0 0 0 1.5px var(--accent)` which isn't clipped by `overflow: hidden`
- Ensure the grid container does NOT have `overflow: hidden` — use `overflow: visible` or `overflow-x: hidden; overflow-y: auto` with sufficient padding

### P6.7 — Library Tabs: Change to Pink Text Highlight
**Problem:** Library tab pills (Albums, Artists, Songs, Genres) use a pink border highlight when focused. Should use bold pink text instead.
**Fix:**
- Active tab (currently selected): keep the subtle background fill (`rgba(255,255,255,0.1)`) and add bold weight (600), `--text-primary` colour
- Focused tab (d-pad hover, not active): text colour changes to `--accent`, font-weight 600. NO outline, NO border, NO background change
- Unfocused tab: `--text-secondary` colour, normal weight
- Remove ALL outline/border-based focus indicators from tab pills
- Override `.focusable.focused` specifically for `.library-tab` elements

### P6.8 — Home Page: Hero Play/Shuffle Buttons — Pink Fill on Focus
**Problem:** The Play button on the Home hero has a pink border highlight. Should fill with pink instead.
**Fix:**
- Play button: already has `--accent` background. When focused, make it brighter/lighter: `background: #f06a9e` (lighter pink) or add `filter: brightness(1.15)`. Remove the pink outline.
- Shuffle button: when focused, fill with `--accent` background and white text. Remove the pink outline.
- Remove ALL outline/border from `.hero-btn.focused` or equivalent class
- Override `.focusable.focused` specifically for hero action buttons

### P6.9 — Album Detail: Reduce Clutter, Smaller Cover Art, Add Padding
**Problem:** Album detail page looks crammed — not enough spacing between elements and the cover art is still too large.
**Fix:**
- Reduce cover art from 240px to 200px
- Reduce left panel width from 260px to 220px
- Add `gap: 40px` between left panel and tracklist (currently may be smaller)
- Add `padding: 16px 0` between the album metadata (title, artist, year) and the Play/Shuffle buttons
- Add `margin-bottom: 12px` between Play and Shuffle buttons
- Ensure tracklist rows have consistent `padding: 12px 16px` with no crowding
- Tracklist panel should have `padding-top: 0` and start aligned with the top of the cover art

### P6.10 — Now Playing: Prevent Scrolling Down to Hidden Player Bar
**Problem:** On the Now Playing screen, pressing Down scrolls the content and reveals half of the "hidden" Now Playing bar.
**Fix:**
- The Now Playing screen must have `overflow: hidden` on its root container — it should not scroll at all
- When the Now Playing screen is active, set `#content-area` to `overflow: hidden` (not `overflow-y: auto`)
- When leaving the Now Playing screen, restore `#content-area` to `overflow-y: auto`
- The Down key on the Now Playing screen should only move between the progress bar zone and the transport controls zone — it should NOT trigger any scrolling
- If the content doesn't fit (unlikely at 1080p), it should be scaled to fit, not scrolled

### P6.11 — Exit Dialogue: Pink Fill Highlight, Consistent Colours
**Problem:** The Cancel button uses a pink border highlight (should be pink fill). The Exit button is a different shade of pink to the rest of the app.
**Fix:**
- Cancel button focus: change from pink outline to pink fill. When focused: `background: var(--accent); color: white`. When not focused: `background: var(--bg-elevated); color: var(--text-primary)`.
- Exit button: change from the current reddish colour to `#ef4444` (red) consistently. When focused: `background: #dc2626; color: white` (darker red). When not focused: `background: #ef4444; color: white`.
- Remove ALL outline/border focus indicators from dialogue buttons
- Both buttons should have the same border-radius (12px) and sizing

## Global Highlight Consistency Rule
After all the above fixes, the highlight pattern across the entire app should be:

| Element Type | Focus Style |
|---|---|
| Sidebar nav items | Active: pink fill. Focused: pink bold text, no border |
| Library tab pills | Focused: pink bold text, no border |
| Hero Play/Shuffle buttons | Focused: pink fill (brighter), no border |
| Album/playlist cards | Focused: thin box-shadow (1.5px accent), scale 1.04 |
| Track/queue rows | Focused: subtle background highlight, no border |
| NP transport icons (small) | Focused: icon colour → pink, no border/glow |
| NP play/pause (large) | Focused: pink glow shadow, no size change |
| Search keyboard keys | Focused: background colour change |
| Dialogue buttons | Focused: pink fill, no border |
| Login inputs | Focused: pink outline (kept — works with IME) |

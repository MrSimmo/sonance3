# P9 — Sonance v1.2.4 Chromium 63 Compatibility Fix

## Overview
**ROOT CAUSE FOUND:** CSS `gap` on flexbox containers is **NOT supported on Chromium 63** (Tizen 5.0 WebView). It was only added in Chrome 84. Every `gap` on a flex container is silently ignored on the TV, resulting in zero spacing between elements.

Additionally, the modern `gap` shorthand for grid was added in Chrome 66. On Chromium 63, only the older `grid-gap` property works.

This explains why the app looks perfect in modern Chrome but has zero spacing between flex children on the TV.

## The Fix
1. **Every `gap` on a flex container** → replace with `margin` on child elements
2. **Every `gap` on a grid container** → replace with `grid-gap` (the legacy property)
3. Fix the login highlight regression from P8

## Tasks

### P9.0 — Global Search and Replace
Search the ENTIRE codebase (all `.css` and `.js` files) for every instance of `gap` being used:

**In CSS files:**
- Find every `gap:` declaration
- Determine if it's on a flex container or grid container
- If flex: replace with margins on children (see pattern below)
- If grid: replace `gap` with `grid-gap`

**In JS files (inline styles):**
- Find every `style.gap` or `gap:` in style strings
- Same replacement logic

**Replacement pattern for flex gap:**
```css
/* BEFORE (broken on Chromium 63): */
.flex-container {
    display: flex;
    gap: 20px;
}

/* AFTER (works on Chromium 63): */
.flex-container {
    display: flex;
}
.flex-container > * + * {
    margin-left: 20px;  /* for horizontal flex (row) */
}
/* OR for vertical flex: */
.flex-container > * + * {
    margin-top: 20px;  /* for vertical flex (column) */
}
```

**The `* + *` (lobotomised owl) selector** adds margin to every child except the first. This is the standard pre-gap pattern.

If `* + *` is awkward in JS-generated DOM, an alternative is to add `margin-right` to all children and negative margin on the container:
```css
.flex-container { margin-right: -20px; }
.flex-container > * { margin-right: 20px; }
```

Or simplest: just add explicit `margin-left` or `margin-right` or `margin-top` or `margin-bottom` when creating elements in JS.

**Replacement pattern for grid gap:**
```css
/* BEFORE: */
.grid-container {
    display: grid;
    gap: 20px 16px;
}

/* AFTER: */
.grid-container {
    display: grid;
    grid-gap: 20px 16px;
}
```

### P9.5 — Login Input Focus Fix
**Problem:** P8 removed all highlighting. Need single pink highlight.
**Fix:**
```css
.login-card input {
    outline: none;
    -webkit-tap-highlight-color: transparent;
}
.login-card input:focus {
    border-color: var(--accent) !important;
    box-shadow: 0 0 0 2px rgba(228, 77, 138, 0.3) !important;
}
```
This uses `border-color` change + outer `box-shadow` glow. No `outline` at all.
